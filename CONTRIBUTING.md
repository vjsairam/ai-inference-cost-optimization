# Contributing

This is a personal evidence project with a frozen v1 scope (TECHNICAL_SPEC.md).

- P0 requirements and milestone acceptance criteria are mandatory; P1/P2 wait for the baseline report.
- Material architecture deviations require an ADR (docs/adrs/) before or with the change.
- Published benchmark data is immutable - new code creates a new run ID.
- Every change states which milestone/requirement IDs it addresses and includes tests.
